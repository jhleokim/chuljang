# 설치 없는 영수증 수집 구조

사용자 요구: 확장 도구·로컬 프로그램 설치 없이, 최초 서비스 연결 이후 출장 날짜 복수 선택만으로 영수증 수집과 지정 양식 저장/메일 공유를 수행한다.

## 현재 동작

- 날짜 복수 선택, 파일 OCR, 저장·검토와 날짜별 조회는 동작한다.
- 확장 도구 설치 CTA 및 설치 가이드는 제품 화면에서 제거했다.
- 설치 없는 자동 수집 백엔드는 연결되지 않았다. 서비스 계정을 연결하거나 수집 작업이 시작된 것처럼 표시하지 않는다.
- collector/는 이전 실험 구현으로 보존하며 설치 없는 제품의 필수 구성요소가 아니다. 기존 수집 패킷의 검토·저장 호환 처리는 보존한다.
- 지정 양식과 메일 연동도 아직 제공되지 않는다.

## 구현 방향

1. 앱 로그인 뒤 서버가 소유자를 확인하고 사용자·서비스별로 격리된 원격 브라우저를 연다.
2. 사용자는 웹의 단기 Live View에서 서비스에 직접 로그인한다. 연결 URL은 소유자만 요청·조회할 수 있게 하고 만료시킨다.
3. 인증 후 서버가 로그인 상태를 암호화하여 격리 보관한다. 비밀번호를 앱 입력란으로 수집하지 않는다. 연결 해제 시 저장 상태와 실행 세션을 삭제한다.
4. 선택한 날짜 집합은 변경 불가능한 작업 데이터로 큐에 넣는다. 서버 브라우저는 검증된 서비스별 조회·날짜·페이지 이동 어댑터로 처리한다. 기존 date-scope/자동 인식 로직을 재사용한다.
5. 추가 인증이 필요한 서비스만 사용자에게 연결 화면을 다시 연다. 다른 서비스 작업은 계속한다. 전체 기간 확인과 일부 수집을 구분한다.
6. 실제 이용일에 해당하는 내역만 중복 없이 저장한다. 사용자 제공 양식으로 생성한 실제 파일만 저장·메일 첨부에 사용한다.

## 현재 필요한 외부 구성

- 원격 브라우저 제공 계정과 실행 자격 증명 또는 브라우저 바인딩. 현재 Sites에는 DB와 BUCKET만 선언되어 있다.
- 지속 작업 실행 환경, 사용자별 암호화 로그인 상태 저장, 큐와 소유자 검증.
- 실제 서비스 계정으로 검증한 읽기 전용 어댑터. 단순 브라우저 연결만으로 모든 사이트 지원을 주장하지 않는다.
- 개인 카카오 T·쏘카의 이용내역 접근 경로. 웹 수집이 불가능하면 공식 연동 또는 이미 수신된 영수증 메일을 사용하되 메일에 없는 내역은 수집했다고 표시하지 않는다.
- 메일 수집/전송은 사용자 OAuth 동의와 운영자 OAuth 앱 설정이 필요하다. 작성 링크는 첨부 전송을 대체하지 않는다.

## 검증한 공식 자료

- Chrome 웹사이트 내 설치 API 폐지: https://developer.chrome.com/docs/extensions/mv2/inline-faq
- 브라우저 출처별 접근 제한: https://developer.mozilla.org/en-US/docs/Web/Security/Defenses/Same-origin_policy
- Cloudflare 원격 로그인 인계: https://developers.cloudflare.com/browser-run/features/human-in-the-loop/
- Cloudflare 인증 상태 재사용: https://developers.cloudflare.com/browser-run/playwright/
- Browserbase 웹 인증 흐름: https://docs.browserbase.com/platform/identity/authentication
- Gmail 서버 OAuth: https://developers.google.com/workspace/gmail/api/auth/web-server

이 문서는 구현 방향이며 서버 수집 연동의 완료 또는 해당 공급자 구매를 의미하지 않는다.
