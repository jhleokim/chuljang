# 출장 Chrome 수집 도구 v3

1. ZIP을 풀고 chrome://extensions의 개발자 모드에서 압축해제된 확장 프로그램으로 연결합니다. 기존 설치는 새 파일로 바꾼 뒤 새로고침합니다.
2. 출장 사이트에 로그인하고 실제 출장 날짜를 여러 개 선택합니다(최대 62일). 수집 버튼을 누르면 최초 한 번만 서비스 접근을 허용합니다.
3. 각 서비스의 기존 Chrome 로그인 상태를 사용합니다. Google 프로필 로그인만으로 모든 서비스에 인증되지는 않습니다.
4. 선택 날짜는 작업과 전송 패킷에 고정합니다. 비연속 날짜의 중간 날은 제외합니다. 발급일·결제일만 있는 내역, 여러 이용일에 걸친 합계는 검토하며 한 날짜에 중복 배분하지 않습니다.
5. 명확한 이용일 범위가 있는 편집 가능한 날짜 입력과 조회 버튼만 자동 설정합니다. 읽기 전용 달력이나 회원 화면의 검증되지 않은 필터는 조작하지 않습니다. 조회 범위 미확인은 그대로 표시합니다. 회원 계정 전체 기간 수집은 아직 실계정 통합 검증 전입니다.
6. 기본 연결은 코레일·KOBUS·대한항공, 아시아나·쏘카 기업은 선택입니다. 개인 카카오 T·쏘카는 앱 영수증 파일을 가져옵니다.
7. 서비스당 선택 날짜 관련 최대 100건, 20개 화면, 검사 2,000건, 30분 제한입니다. 조회 한도나 범위 미확인 시 전체 수집 완료로 표시하지 않습니다. iframe·PDF 자동 다운로드는 지원하지 않습니다.
8. 저장 대기 큐와 작업은 Chrome 세션에 30분간 보관합니다. 저장 또는 명시적 제외 때만 삭제합니다. 선택 날짜와 서비스 설정은 이 기기의 Chrome 설정에 남습니다. Chrome 시작 시 다시 수집은 기본 꺼짐이며 켜면 마지막으로 선택한 날짜만 6시간 간격으로 다시 확인합니다.

비밀번호·쿠키·카드·인증 입력은 읽거나 전송하지 않습니다. 날짜 입력만 설정·검증합니다. 전송 대상은 고정된 출장 사이트이며 다른 사용자 탭은 탐색하지 않습니다. 사용자 정산 양식과 메일 연동은 아직 설정되지 않았습니다.
