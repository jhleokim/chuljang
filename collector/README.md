# 출장 영수증 수집 도구
Chrome Manifest V3. 압축을 풀고 확장 프로그램 관리의 개발자 모드에서 폴더를 로드합니다.

1. 서비스에서 직접 로그인하고 발급된 영수증을 엽니다.
2. 필요한 텍스트를 선택하거나 영수증 페이지를 그대로 둡니다.
3. 확장 도구에서 서비스 선택 → 현재 페이지 읽기.
4. 전송 텍스트를 확인하고 출장으로 보내기.
5. 출장 사이트에 로그인하고 추출된 날짜·원화 금액을 검토한 뒤 저장.

인증정보, 쿠키, 입력 필드는 수집하지 않습니다. 현재 탭의 선택 텍스트 또는 표시된 표/본문만 읽습니다. 다른 페이지로 이동하거나 계정의 전체 과거 내역을 수집하지 않습니다. 인식은 한국어 날짜와 금액 표시에 기반하며 사이트 전용 비공개 API를 사용하지 않습니다. 실제 서비스 계정 화면의 구조 변경에 따라 동작하지 않을 수 있습니다.

미전송 텍스트는 팝업이 닫힐 때 없어집니다. 전송 대기 데이터는 브라우저 세션 메모리에 최대 20분 보관 후 조회 시 폐기되며, 정상 전달하면 즉시 삭제됩니다. 저장 대상은 https://chuljang-receipts.jhleokim.chatgpt.site/ 로 고정합니다.
