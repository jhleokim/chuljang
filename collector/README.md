1. 수집 도구의 ‘연결하고 모두 가져오기’를 누르고 선택한 서비스 접근을 허용합니다.
2. 로그인된 서비스는 자동으로 조회합니다. 로그인·조회 확인이 필요한 서비스만 해당 버튼을 누릅니다.

4. Chrome 시작 시 자동 수집은 설정에서 끌 수 있습니다. 켜져 있으면 마지막 수집 후 6시간이 지난 Chrome 시작 시 실행합니다.
